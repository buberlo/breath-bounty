# Breath Bounty

> Your exhale is oxygen currency for a tiny coastal kingdom.

Breathe into the mic to pay citizens, keep the lighthouse powered, and earn civic decorations. If you rush or skip breaths, the council files lung complaints and taxes your idle air.

## Features
- Real-time mic amplitude detects inhales, exhales, and breath holds
- Oxygen treasury pays citizens for each qualified exhale
- Civic complaint inbox tracks rushed breaths and skipped breaths
- Unlock lighthouse upgrades that reduce breathing tax

## Stack
- React Native
- Expo Audio
- SQLite

## Getting started
```
npm install && npx expo start
```
